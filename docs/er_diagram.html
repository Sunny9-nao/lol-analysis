全体設計の特徴 (ADR 0003 準拠)

ハイブリッド・データモデリング Riot Games API の試合生データ（10人分の膨大な情報）は matches.raw_info にそのまま保存。 分析や検索で頻繁にソート・絞り込みを行う項目（勝敗、14分時点の差、対面チャンピオン名）のみを match_participants の正規化カラムとして切り出しています。
中心ハブ: match_participants 「どのプレイヤーが」「どの試合で」「誰と戦ったか」の全データを集約。ユーザーの反省メモ（match_notes）もこのレコードに紐付きます。

キー記号の凡例

  • PK : Primary Key (主キー)
  • FK : Foreign Key (外部キー)
  • UK : Unique Key (一意制約)
