# [ADR-0010] ソロランク向上ユースケースの実現方針と全体UI/情報設計アーキテクチャ

- **ステータス**: Accepted
- **決定日**: 2026-09-05
- **決定者**: チーム / 開発者

---

## コンテキスト（背景・課題）

当プロダクトは「**プレイヤー自身がソロランクでLPを上げる（勝率を改善する）ためのパーソナルPDCAツール**」である。
一般的な統計サイト（OP.GG等）のような全プレイヤー平均のメタデータではなく、「自分自身の成功・失敗パターン、対面別の癖、過去の教訓」を蓄積し、実際のランクマッチ前後でストレスなく活用できることが求められる。

プレイヤーの行動サイクル（インキュー ➔ マッチ確定 ➔ 試合直後 ➔ オフ時の振り返り）に沿ってユースケースを定義し、個別の機能を場当たり的に追加してUIが散らかるのを防ぐため、**各ユースケースの実現方針（データ・計算ロジック）と全体UI情報設計（Information Architecture）**を統一して決定する。

---

## 決定事項 (Decision)

### 1. 採用するユースケースと実現方針

#### 【A. 流れに沿ったユースケース（インキュー〜試合後）】

1. **UC-A1: チャンプセレクト時の相手チャンプ逆引きレコメンド（後出し対応）**
   - **目的**: 相手が先に確定した際（例: 相手がAatrox）、自分のプール（Renekton, Jax等）の中で誰が一番対面勝率が高いかを瞬時に把握する。
   - **データ**: ローカルDB内の相手チャンプ別・自チャンプ別対面集計データ。
   - **UI**: 相手チャンプ名を入力・選択すると、自分のプール内のチャンプを対面勝率順（KDA、CS/分、過去メモ）に横並び比較表示。

2. **UC-A2: マッチアップ確定時のチートシート（カンペモード）**
   - **目的**: ロード中（30秒〜1分）の慌ただしいタイミングで、過去の教訓や勝利時のビルドを即座に頭に入れる。
   - **データ**: 過去の反省メモ一覧、勝利した試合のコアアイテム、キーストンルーン、過去の対面戦績。
   - **UI**: 余計な文字や数字を削ぎ落とし、大文字・箇条書きの全画面/大型モーダル（`CheatSheetModal`）で1秒表示。

3. **UC-A3: 試合直後のクイック反省メモ（摩擦ゼロ入力）**
   - **目的**: 試合終了直後、記憶が鮮明なうちに数タップで敗因・反省を記録する。
   - **データ**: 直前試合サジェスト、クイック要因タグ（`Lv1-3ソロキル被弾`, `ガンク被弾`, `ウェーブ管理ミス`, `スキルCDトレード負け` 等）。
   - **UI**: 画面最上部に直前試合をサジェスト表示（未記入時は入力ボタンが強調）。モーダル内でタグをタップするだけでメモに即挿入。

---

#### 【B. 振り返る場合のユースケース（オフ時・総合分析）】

4. **UC-B1: 得意・苦手マッチアップ＆使用チャンプ勝率傾向の把握**
   - **目的**: 自分のプールの全体像と、天敵・カモを俯瞰する。
   - **データ**: 試合数（2試合以上等の閾値設定で偶発的な100%/0%を除外）、勝率、Hardタグ比率。
   - **UI**: 天敵ワースト＆得意ベストのインサイトカード、対面一覧ソート（勝率順・Hard順）。

5. **UC-B2: 対戦日時の明記と一覧視認性**
   - **目的**: いつの試合かが直感的にわかるようにする。
   - **データ**: `matches.game_creation`（UNIXタイムスタンプ）。
   - **UI**: 「2時間前」「昨日」「9月4日 21:30」のように相対時間＋絶対日時を明記。

6. **UC-B3: ランクポイント（LP / ティア）の推移記録・可視化**
   - **目的**: ランクが上がっている実感と、調子の波を把握する。
   - **データ**: Riot API `League-V4` (`/lol/league/v4/entries/by-puuid/{puuid}`) から取得するTier, Rank, LP。
   - **ロジック**: 試合同期時にその時点のLPをスナップショットとして保存し、推移グラフを描画。

7. **UC-B4: ミスの傾向・敗因タグ集計（弱点の可視化）**
   - **目的**: 「直近20試合で一番多い敗因」を客観的に把握し、次の試合の改善目標を立てる。
   - **データ**: メモ内に含まれる要因タグ（`【ガンク被弾】` など）。
   - **ロジック**: 直近20試合の要因タグ出現回数を集計し、ワースト順にパーセンテージとプログレスバーで可視化。

8. **UC-B5: レーン戦勝敗（Timeline API）vs 試合結果の4象限ギャップ分析**
   - **目的**: 「レーン戦では勝っているのに試合に負けている（集団戦やマクロの課題）」のか、「レーンで負けて崩壊している」のかを切り分ける。
   - **データ**: Riot API `Match-Timeline-V5` (`/lol/match/v5/matches/{matchId}/timeline`)。
   - **ロジック**:
     - 14分時点（プレート消滅）の対面ゴールド差（GD@14）およびソロキル数からレーン勝敗を自動判定：
       - `Lane Win`: GD@14 >= +500G または ソロキル先行
       - `Lane Even`: GD@14 ±500G
       - `Lane Loss`: GD@14 <= -500G
     - 最終結果（Win/Loss）と掛け合わせた4象限：
       1. レーン勝ち ➔ 試合勝利（順当スノーボール）
       2. **レーン勝ち ➔ 試合敗北（要分析：逆転負け / マクロ差）**
       3. レーン負け ➔ 試合勝利（キャリー勝ち / 捲り）
       4. レーン負け ➔ 試合敗北（レーン崩壊）

### 2. 全体UI情報設計（Information Architecture）

画面があちこちにボタンやカードで散らかるのを防ぐため、以下の**「3層構造 ＋ 3タブ構成」**にUIを整理・集約する。

```
+-------------------------------------------------------------------------------+
|  Header: [LoL Matchup Lab]          [ Sunny9#hono (Ranked Solo/Duo) 🔍 ]       |
+-------------------------------------------------------------------------------+
|  層1: サモナー基本情報 & LPサマリ (Lv.487 / Emerald IV 45LP 📈)              |
+-------------------------------------------------------------------------------+
|  層2: [直前のソロランク試合サジェスト] (未反省時のみハイライト表示)           |
|       vs Jax (敗北) - KDA: 2/6/3 | [ ⚠️ 今すぐ反省メモを残す (1クリック) ]    |
+-------------------------------------------------------------------------------+
|  層3: メインナビゲーションタブ                                                 |
|       [ ⚔️ 対面分析・対策 ]    [ 📊 弱点・ギャップ分析 ]    [ 📜 試合履歴 ]    |
+-------------------------------------------------------------------------------+
|                                                                               |
|  【タブ1: 対面分析・対策 (Matchup Lab)】 (UC-A1, UC-A2, UC-B1)                |
|  - 自チャンプセレクタ [ Renekton ▼ ]                                          |
|  - [相手チャンプ逆引き検索]: 「Aatrox」と入力 ➜ あなたの最高勝率チャンプを提示 |
|  - 天敵ワースト & 得意ベスト ハイライトカード                                  |
|  - 対面一覧カード (ソート・検索・「📋 カンペ」ボタン ＆ 過去試合アコーディオン) |
|                                                                               |
|  【タブ2: 弱点・ギャップ分析 (Performance & Gap)】 (UC-B4, UC-B5)             |
|  - 4象限マトリクス (レーン勝率 vs 試合勝率 / 逆転負け試合の抽出)              |
|  - 敗因タグワーストランキング (1位: ガンク被弾 40%, 2位: スキルCDトレード 25%)|
|                                                                               |
|  【タブ3: 試合履歴 (Match History)】 (UC-B2)                                  |
|  - 対戦日時 (相対時間 + 絶対日時) を明記した試合カード一覧                    |
|  - 勝敗、KDA、CS、アイテム、メモプレビュー                                    |
+-------------------------------------------------------------------------------+
```

## 実施ロードマップ

1. **フェーズ1: 全体デザイン枠組みの最適化 ＆ 即効性の高い改善**
   - 全体レイアウト（3タブ構成）の整理
   - 相手チャンプ逆引き検索機能（UC-A1）の実装
   - 試合履歴への対戦日時（相対時間＋絶対日時）の明記（UC-B2）
2. **フェーズ2: 主観データの集計・可視化**
   - 敗因タグの自動集計ワーストランキング（UC-B4）の実装
   - Riot API `League-V4` によるLP取得と推移記録の導入（UC-B3）
3. **フェーズ3: 客観Timeline APIの連携**
   - `Match-Timeline-V5` による14分時点のゴールド差・CS差取得
   - レーン戦勝敗 vs 試合結果の4象限ギャップ分析（UC-B5）の実装
