# [ADR-0008] フロントエンド基盤の技術選定とGoogle風クリーンデザインUIの策定

- **ステータス**: Accepted
- **決定日**: 2026-09-05
- **決定者**: チーム / 開発者

## コンテキスト（背景・課題）
ADR-0001 および ADR-0007 により、Rails 8 GraphQL BFF と対面分析クエリ（Matchup Analysis）が整備された。
ユーザーがブラウザ上でサモナー検索、直近の戦績閲覧、対面別分析、および反省メモの入力・編集を行えるようにするため、フロントエンドアプリケーション（`frontend/`）の技術選定とUIデザイン方針を策定・実装する必要がある。

## 検討した選択肢
1. **技術スタック**:
   - Next.js (App Router) + TypeScript + Tailwind CSS: 実務でのReact利用経験との親和性が高く、高速なビルドと型安全性を享受できる。
   - Vite + React SPA: シンプルだが、将来のSSR/OGPやNext.jsエコシステムの活用を踏まえるとNext.jsが優位。
2. **ビジュアルデザイン**:
   - 暗色系のゲーミングUI（OP.GG風ダークネイビー）
   - Googleライクなクリーンデザイン（白・グレー・青・黒基調）（採用）
     - メリット: 清潔感があり、分析データや反省メモ（テキスト）の視認性・可読性が極めて高い。Google風のピル型検索バーやタブUIと親和性が高い。
3. **対面分析のインタラクション**:
   - 画面遷移 / 別ページ型
   - ポップアップモーダル型
   - インラインアコーディオン展開型（採用）
     - メリット: カードをクリックするとその場で前後の対面を見失わずに過去試合とメモを比較・閲覧できる。

## 決定事項 (Decision)
1. **Next.js App Router + TypeScript + Tailwind CSS の採用**:
   - `frontend/` に Next.js 16 (React 19) プロジェクトを初期化し、TypeScript と Tailwind CSS を標準構成とする。
   - アイコンライブラリとして `lucide-react` を採用する。
2. **Google風クリーンデザインの採用**:
   - カラーパレット: 白 (`#ffffff`)、ライトグレー (`#f8f9fa`, `#f1f3f4`)、ボーダー (`#dadce0`)、テキスト (`#202124`)、アクセント (`#1a73e8`)。
   - 勝敗バッジ: 勝利＝ブルー系 (`#e8f0fe` / `#1967d2`)、敗北＝レッド系 (`#fce8e6` / `#c5221f`)。
3. **タブナビゲーションとインラインアコーディオン**:
   - サモナー基本情報の下に「対面分析 (Matchup)」と「直近の試合一覧」のタブを配置。
   - 対面分析タブでは自チャンピオン選択ピルバーを配置し、対面カードをクリックすることでインラインアコーディオン展開し、過去試合詳細とメモを表示・編集可能とする。
4. **GraphQLクライアント**:
   - 軽量な `fetch` ベースのクライアントヘルパー（`src/lib/graphql-client.ts`）を実装し、Rails API（`http://localhost:3001/graphql`）と通信する。

## 結果と影響 (Consequences)
### ポジティブな影響（メリット）
- プロトタイプ通りの洗練されたUIがReactコードとして完全に具現化され、即座にブラウザで動作確認可能となった。
- メモ編集時に楽観的更新（UI即時反映）が行われるため、軽快な操作性を実現。
- 型定義（`src/types/graphql.ts`）により、バックエンドのGraphQLスキーマ変更にも安全に対応可能。

### ネガティブな影響 / トレードオフ
- 現時点では認証が未導入のため、メモ編集はローカルでの検証用として動作する（後続の認証導入でセッショントークンを付与する予定）。
